Command line (CLI) options

each holds for this run only and is not written to the settings

 --video-out FILE record from the start into FILE; .mp4 or .mkv picks the container
 --video-auto switch the autostart and the autostop on, with the conditions set in the options
 --no-video-auto switch both off
 --video-autostart AT start when AT is met, once after each reset
 --video-autostop AT stop any recording when AT is met

AT

 ram start: the first code run from RAM, the system area #5B00-#5CCA aside
 reset stop: a reset - F12, the menu, the debugger, a file started
 ==ADR the PC equals ADR; the same as ADR alone
 >=ADR the PC is ADR or above
 <=ADR the PC is ADR or below

ADR

 #6000  $6000  0x6000 in hex
 24576 in decimal

Examples

 --video-auto demo.sna as the options say
 --video-autostart ram --video-autostop reset from the program's first code to a reset
 --video-autostart 0x8000 --video-autostop "<=#3FFF" from #8000 to the first call into ROM
 --video-out C:\videos\demo.mkv all of it, into that file

put <, > and a leading # in quotes: a shell reads them as redirections and a comment
