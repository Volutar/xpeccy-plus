# esp-bench cases: the Next with the emulated ESP-01 on UART 0 and a server on 127.0.0.1.
#
#   bin  <file in bin/>  <source in asm/>  [DEFINE=value ...]   how mkbins.py assembles it
#   run  <case>  <file in bin/>  <frames>  [ENV=value ...]      one run of esp-bench
#
# A run with SCRIPT=<file in scripts/> is a script through bridge.bin (main.cpp says how).
