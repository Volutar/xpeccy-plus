# Help menu

```{index} Help, Manual, Project Page, What's New, Report a Problem, Check for Updates, About
```

An item with a box and an arrow at its right end opens a page in your browser.

- **Manual** - this manual, from the program's own files; see
  [This manual](getting-started.md#this-manual). A build that came without them opens the
  copy on the web, and then the item has the mark.
- **Project Page** - the project's page on GitHub, in your browser.
- **What's New** - the list of changes of every version.
- **Report a Problem** - the page where problems are reported. Say which version you run
  (it is in **About**), on which system, and what you did; a log helps too (see
  [Application page](options-application.md)).
- **Check for Updates...** - ask GitHub now whether a newer version is out; see
  [Updates](getting-started.md#updates).
- **About Xpeccy+** - the version, the versions of Qt and SDL it was built with, and the
  terms of the parts that come with it. On macOS it is in the application menu.
